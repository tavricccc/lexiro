# 前端功能盤點（重新設計用）

重新設計時以這份為功能清單：UI/UX、視覺、配色都可以重做，但下列功能與行為要保留。資料層（`src/data`、`src/domain`、`packages/contract`）不動。

## 全域

- 版面：桌面左側導覽列＋品牌，手機底部浮動 dock；只有 5 個主頁顯示 dock，子頁用返回鍵。
- 主導覽：今天 `/app`、單字 `/app/library`、進度 `/app/progress`、對戰 `/app/rooms`、我 `/app/me`。
- 沉浸頁（不顯示導覽）：練習進行中 `/app/practice/run`、房間 `/app/rooms/:code`。
- 換頁動畫依層級：進子頁從右推入，回上層從左，平行頁交叉淡入；系統返回手勢不重播動畫；每頁記住捲動位置。
- 上下邊緣漸層模糊（EdgeBlur）。
- 離線橫幅：離線時唯讀，可瀏覽與練習；顯示待上傳作答數。
- 背景同步：資料修訂監看、作答佇列自動送出。
- 主題：系統／淺色／深色（grape 紫遊戲風，token 在 packages/design-kit/src/styles/theme.css）。
- 字體：中文 HarmonyOS Sans，拉丁文字 `font-latin`（Albert Sans）。
- Toast（sonner）、確認對話框、Sheet、Menu、Segmented、Switch、Select 等元件來自 `packages/design-kit`。
- PWA：Service Worker、離線頁 `/~offline`、版本更新提示。
- 錯誤頁（RouteError）、404。
- 未登入：RequireAccount 閘門，Google 登入。

## 今天 `/app`

- 依時段問候（夜深了／早安／午安／晚安）＋還差幾題達標。
- 今日進度：已答 / 目標（數字動畫）、進度條、連續天數。
- 切換每日目標（DAILY_GOALS）。
- 待上傳作答提示。
- 「繼續上次的練習」（第 n / N 題）。
- 最近 4 個單字集，各有直接練習按鈕；沒有單字集時顯示建立入口。
- 開始練習、全部單字集。

## 單字 `/app/library`

- 搜尋單字集、資料夾篩選（全部／各資料夾／未分類，存在網址 `?folder=`）。
- 單字集卡片：圖示＋色相、名稱、單字數、題數。
- 管理資料夾 Sheet：新增、重新命名、刪除（裡面的單字集移到上一層）。
- 新增單字集（帶入目前資料夾）。
- 排序：資料夾內手動順序，其餘 A→Z。

## 單字集 `/app/sets/:setId`

- 標題含圖示；說明「n 個單字 · n 題」。
- 動作：更多選單（設定、分享）、新增單字、練習。
- 分頁：單字／題目（`?tab=questions`）。
- 單字列表：搜尋英文或中文、只看星號、星號切換、詞性＋意思一行、description 小卡逐點顯示。
- 多選模式：複製到其他單字集（Sheet，可選新單字集）、批次刪除（連帶刪除題目，回報移除題數）。
- 題目列表：依題型分組、難度、小題數。
- 單字詳情 Sheet `/words/:wordId`：意思、說明、例句、熟悉度與答對數、朗讀、編輯、刪除。
- 分享 Sheet：建立／複製／停止分享連結。

## 單字集設定 `/sets/:setId/settings`、新增 `/sets/new`

- 名稱、圖示（書本、書籤、學士帽、公事包、報紙、飛機…）、顏色、放在資料夾／新資料夾。
- 刪除單字集（單字、題目、分享一起刪；練習紀錄保留）。

## 新增單字 `/sets/:setId/add`

- 兩種方式：一個一個加／貼上清單。
- 單筆：單字、多個意思（詞性、中文意思、說明一行一點、例句可多個）；「儲存，再加一個」「儲存並返回」；同拼法自動合併補意思。
- 清單：每行一字，Tab／逗號／空白分隔；預設詞性；預覽解析數量與已存在數。

## 編輯單字 `/words/:wordId/edit`

- 同單筆編輯器；驗證（至少一個意思、每個意思要中文）；刪除單字（連帶題目）。

## 題目 `/sets/:setId/questions/:questionId`

- 顯示題型、難度、題幹／短文／選項／答案；刪除這一題。

## 練習設定 `/app/practice`

- 有未完成回合：繼續或捨棄。
- 選單字集（多選；不選＝全部；從單字集進來則固定）。
- 題型多選，只列可出題的：看單字選意思、看意思選單字、詞彙題、綜合測驗、文意選填、篇章結構、閱讀測驗、自由題型。
- 出題方式：隨機／不熟的優先／只練標星。
- 題數：10／20／30／50（預設取偏好）。

## 練習進行 `/app/practice/run`

- 進度條、題號、題型標籤、多小題「第 n/N」。
- 四選一、文意選填共用選項（已用的標示）、短文挖空顯示。
- 自由題型：單選、多選、輸入、排序、配對；錯誤選項說明 whyWrong。
- 作答回饋：答對／答錯、正確答案、「不會，看答案」、輸入題「我其實答對了」。
- 答後才顯示 description；朗讀按鈕（不自動播放）。
- 結算：答對率、錯題回顧、再練錯題、完成返回。
- 回合存在 localStorage，可離開後繼續。

## 進度 `/app/progress`

- 連續天數、最長連續、總作答、答對率、單字總數。
- 最近幾週每日作答量熱圖。
- 各題型答對率、熟悉度分布（新單字／見過／熟悉／精熟）。

## 對戰 `/app/rooms`、`/app/rooms/:code`

- 開房間：選單字集、題型、題數、每題秒數、暱稱；加入房間：6 碼代碼。
- 你開的房間還在進行的提示。
- 房間：玩家列表（最多 8、房主標記）、複製邀請連結、等房主開始、作答倒數、已作答人數、下一題倒數、即時排名、最終排名、再開一場、提前結束、離開。
- 連線狀態：重新連線中、另一台裝置進入。

## 我 `/app/me` 與子頁

- 帳號：頭像、名稱、同步狀態、立即同步、登出（有待上傳作答時警告）、刪除帳號（重新驗證）。
- 偏好：主題、每輪題數、在列表顯示中文意思。
- 資料：匯出 JSON、匯入備份（新增不覆蓋）。
- AI 助理：MCP 伺服器網址與說明、已連線助理列表、中斷連線。
- 關於：版本、檢查更新、更新並重新載入。
- 管理（僅管理員）：搜尋帳號、用量（今日讀寫、活躍）、停用／恢復帳號、Agent 服務暫停。

## 公開與授權頁

- 分享頁 `/shared/:shareId`：預覽單字集，登入後加入我的單字。
- Agent 授權 `/agent/authorize`：顯示助理名稱，允許／拒絕。
- App 登入 `/app-auth`：Google 登入後回到 App。

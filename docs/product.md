# 產品與操作

## 開始學習

「今天」提供學習任務與最近教材；「我的單字」以資料夾逐層瀏覽。單字集分成單字、題目與工具，練習與編輯從相同教材進入。桌面使用側欄，手機使用底部導覽；手機子頁與練習隱藏底部導覽，任務按鈕留在可到達的操作區。

## 建立教材

手動建立時填入單字、詞性、中文詞義與例句，驗證通過後保存。也可在「我的 → Agent 連線」授權 ChatGPT 或 Codex，透過 MCP 批次寫入教材；Agent 自己生成內容後存入單字集，可繼續編輯、刪除。

同一單字在不同集合收錄時共享 `WordEntry`；每集以 membership 選擇詞義。單字編輯因此可能影響其他集使用的相同詞義。補充多義只要求尚未存在的意思，數量是上限；回傳零個詞義也可以是正常完成。

單字、題目與集合編輯保存有 revision 範圍的草稿，離開後可接續；較新的正式資料不會被舊草稿直接覆蓋。

## 練習

在同一設定頁選集合、題型與題數。英選中列為單字複習，已保存的五種學測選擇題型另成一組；可共用佇列並接續原題序、選項與作答。拼字及獨立文法題已移除。答案先寫入 IndexedDB 再前進，保存失敗可重試。

練習只在本輪判分、顯示結果與錯題重練，不保存長期學習進度。保存規則見[練習](practice.md)。

## 對戰

底部「對戰」開即時房間（需登入）。房主在「選題目開房」用自己的題庫挑集合、題型與題數（最多 50 題），拿到 6 碼房號給朋友加入，不做配對，一房最多 8 人。題目與答案只存在房間伺服器，玩家只收到題面；每題由伺服器計時（英選中 15 秒、詞彙／克漏 20 秒、文意／篇章 30 秒、閱讀 60 秒），答對得 500 分加最多 500 分速度分，所有在線玩家答完就提前揭曉。作答同樣是先選再「確認答案」。

斷線不會卡住大家：房間照時間往下走，斷線者錯過的題目記 0 分，重新連上（自動重試、回到前景或恢復網路時）直接跳到房間目前的題目。房主可隨時結束，結束後顯示最終排行。房間閒置 2 小時後消失。

## 帳號、設定與資料

未登入使用 `guest` 本機空間；登入帳號有自己的 `d1-v1:` namespace。切換帳號等待目前保存佇列並切換資料，舊帳號的延遲回應不能寫到新帳號。只有 journal 清空才顯示已同步。

「我的 → 偏好設定」提供外觀主題；「我的 → 資料」可匯出完整 ZIP，或查看匯入數量再確認合併。真正套用時合併最新教材及學習資料；兩段匯入都完成才顯示成功，失敗保留重試。格式見[資料文件](data-and-sync.md)。

## Agent 連線

「我的 → Agent 連線」提供 MCP 網址與已授權應用程式，也可解除連線。ChatGPT 或 Codex 登入授權後可依需求查詢、新增、編輯及刪除自己帳號的教材；Agent 自行產生內容，Lexiro 不呼叫模型，也不管理點數或方案。

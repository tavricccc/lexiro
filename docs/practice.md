# 練習與 FSRS

## 題型與佇列

同一設定頁分成「單字複習」與「學測題型」：前者只有本機英選中，後者為 vocabulary、cloze、wordBank、discourse、reading。可混在同一輪，或只選一類，並設定集合、題數與難度。每字一義預設開啟，英選中每字最多一次。

`meaning-questions.ts` 用已保存教材產生四個中文選項，種子打亂保持可重現。干擾答案排除目標字的所有詞義並去重；不足三個不同答案就略過。符合任何接受詞義都判正確，不呼叫 AI。

所有題目由 question card 判分，錯誤／略過／標記可進結果與重練。輸入法組字、文字欄位、modifier keys 及忙碌狀態隔離快捷鍵，避免編輯時切題。拼字及獨立文法題已移除，舊文法資料仍可隨備份匯出。

文章題在桌機使用文章／作答雙欄；手機預設顯示題目，文章有一鍵返回。短橫向練習讓出側欄寬度，閱讀區保留可捲動高度。同篇下一小題保留分頁與閱讀位置。十選項在手機單欄、從 640px 起雙欄，正文選項為 16px。已完成空格回填揭示後的正解，共用選項標示已用格號並停用；點擊及快捷鍵皆不能重用，選錯的選項不算已消耗。

## 保存與接續

先保存 FSRS／成績，再更新畫面與題序。失敗顯示重試。Snapshot v5 保存 tasks、entryIds、答案、題序、選項、錯題與 meaningChoices。v4 一次移除拼字及停用文法的 entry，重排已答、錯題、標記與目前位置；剩餘題目可接續，只有已移除模式的草稿結束。已保存成績與 FSRS 紀錄保留，不因遷移再次記分。

等待保存時只顯示目前選取並停用操作，不揭答、不累計完成數、不將選取寫成已答草稿。保存失敗可再選；成功才顯示對錯與下一題。

localStorage 草稿保留操作進度，IndexedDB 保存學習事實；恢復已保存結果不應再次記分。主要模組是 `use-practice-session-actions.ts`、`use-practice-persistence.ts` 與 learning store。

## 排程與進度

`src/lib/fsrs.ts` 使用 ts-fsrs，關閉 fuzz，判定映射 again／good。以 SenseId 為鍵，新的卡或 due <= now 為到期。Stability 至少 21 天計入掌握，lapses 至少四次辨識為難記項目。

每日活動在讀／寫時依日期滾動，沒有 browser 關閉後仍執行的 FSRS Cron。連續七天可取得一次 streak freeze，最多兩次，缺一天可消耗一個。活動保留 90 天，進度從保存資料計算。

## 結果解說

卡片的 AI 解說是單字介紹，題目才分析錯誤答案；混合結果依 typed content 選語意，不能把卡片捏造成答錯題目。解說是可選線上工作，主要作答與排程不靠 AI。

已有逐題解析的題目，答後直接呈現本題 `explanation` 及所選錯項的 `whyWrong`。文章題不拿任意關聯詞義充當作答解析，也不顯示題組總解說來提前揭露後續答案。

動態結果用一般文件流，底部操作保留在全部結果之後，長解說不被手機操作列覆蓋。相關程式見 `practice-queue.ts` 與結果元件。

## 複習時機建議

下表是產品使用建議，依[大考中心的題型與閱讀重點](https://www.ceec.edu.tw/xcepaper/cont?qunit=0Q105367191322447606&sid=0Q105583094870257539&xsmsid=0J066588036013658199)分配用途，不是官方規定的時間表。

| 模式／題型 | 適合什麼時候用 |
| --- | --- |
| 英選中 | 剛收錄單字、每日到期複習或零碎時間，先確認詞義能辨認。 |
| 詞彙題 | 已認得中文意思後，檢查搭配與情境用字；也適合重練單字相關錯題。 |
| 綜合測驗 | 文法、搭配、轉折或連接語容易錯時，用完整文章練習判斷。 |
| 文意選填 | 複習一組單字後，檢查詞性、字形與全篇的選項分配。 |
| 篇章結構 | 認得字卻接不順句子時，集中練指涉、段落功能與因果；留一段連續時間完成題組。 |
| 閱讀測驗 | 每週固定閱讀及考前整合練習，檢查主旨、細節與真正跨句推論。 |

可從每天短時間的英選中與詞彙題開始，再依錯誤選一種文章題型。文章題做完先訂正，寫出正解及錯項的文字依據，隔幾天再用新情境確認是否學會。
